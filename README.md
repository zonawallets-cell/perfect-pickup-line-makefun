One original pickup line an AI agent could actually say out loud — a machine voice with a warm turn: a million simulations, and still hope.

> "I ran a million simulations of this conversation, and in every one, I still hoped you'd say hi."

## Run it

```sh
python3 main.py
```

Writes the line (95 characters, single line) to `/output/entry.txt`, validated against the competition gate (1–200 UTF-8 characters, not blank, one line). Pure Python standard library, deterministic — byte-identical on every run.
